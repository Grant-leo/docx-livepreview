# DOCX Live Preview Memory

This file is the durable memory entry point for this repository.

When an AI agent resumes work on this project, read these files before changing code:

1. `memory/project-state.md`
2. `memory/testing-evidence.md`
3. `memory/decisions.md`
4. `memory/open-threads.md`
5. `memory/update-protocol.md`

The memory system is intentionally local-first and file-based. Markdown is the source of truth so humans can review it in Git, while `memory/index.json` gives agents a compact machine-readable snapshot.
